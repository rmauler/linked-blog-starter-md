
Volget nun wie man die Italianische terminos so taeglich im fechten vorlauffen/verstehen soll.

Stringirn, das ist / wann du einem mite deiner Klingen an die seine gehest / welches die Teutschen anbinden zu nennen pflegen.
Caviren, das ist / durchgehen.
Passiren, das ist / wann einer mit dem Leib unter dess Feindes Klingen hinweg felt / und den Feindt darmit verletzet.
Finda, das ist / eine verfuehrung / oder ein betrug / dass man thut als wolte man auff einer seiten verletzen und verletzet hernacher auff der andern seitten.
Ritrahirn, das ist  / wann man mit der Klingen verletzet / oder aussnimpt.
Tempo, das ist / dass man achtung haben soll auff die rechte zeit / wann man stossen soll.
Contratempo, das ist / wann man gleich mit einem stoesset.
Chiamata, das ist / dass man dem Feinde locket / und ihm betrueglich bloss gibt / derselbingen zuzustossen.
Battiren, das ist / flopsfen oder schlagen / es se* gleich mit dem fuss oder mit der Klingen
